# 本地扩展安装与使用

本版支持 Chrome 和 Edge（Manifest V3），Firefox 启动功能仍保留，但本扩展不直接支持 Firefox。

## 安装一次

1. 在普通 Chrome 地址栏打开 `chrome://extensions`；Edge 则打开 `edge://extensions`。
2. 开启“开发者模式”，点击“加载已解压的扩展程序”。
3. 选择项目目录中的 `extension` 文件夹（例如 `D:\GPT-AutoLogintor\extension`）。它包含 `manifest.json`；文件夹选择器不会显示普通文件，进入该目录后直接点击“选择文件夹”。换电脑后使用新克隆目录内的 `extension`，无需保持相同盘符。
4. 打开扩展“详情”，开启“允许在无痕模式下运行”（Edge 为“允许在 InPrivate 中使用”）。这是浏览器要求用户手动授予的权限，程序不会替你开启。
5. 在扩展网站访问权限中允许访问 `https://chatgpt.com/*`，可将扩展固定到工具栏。

安装后保留此目录。代码更新后，在扩展管理页点击扩展的“重新加载”。

## 每次使用

1. 用本地工具打开 Chrome 无痕或 Edge InPrivate 窗口，停留在 `https://chatgpt.com/`。
2. 在该无痕窗口中点击本扩展图标；提示“当前目标：ChatGPT 无痕会话”后才可操作。
3. 将自己的或获账号本人明确授权的 `sessionToken` 粘贴进扩展。只粘贴令牌本身，不是整个 JSON；完整 JSON 可先在原工具中提取。
4. 点击“导入并刷新当前页”。扩展先清除目标存储区内旧的根路径登录 Cookie 及其数字后缀分段，再写入新令牌、核对并刷新当前页。
5. 在网页中核对实际账号。Cookie 写入成功不代表网站接受该会话，也不保证消除 Cloudflare 验证；必要验证须由用户正常完成。

## 清除与作用范围

- 扩展“清除登录 Cookie”只删除目标无痕存储区内 `chatgpt.com` 根路径的 `__Secure-next-auth.session-token` 和数字后缀分段。不会删除 Cloudflare Cookie、其他站点 Cookie、Local Storage、IndexedDB 等，也不撤销服务端令牌。清除后请手动刷新网页。
- 同一无痕 Cookie 存储区可能由多个无痕窗口/标签共享，导入或清除会影响其中所有 ChatGPT 标签。普通窗口的 Cookie 不受影响。
- 若需完整结束隐私会话，请关闭该浏览器同一配置下的全部无痕窗口。
- 点击导入后输入立即清空；令牌只暂存在扩展内存和目标会话 Cookie 中，不写日志、不使用扩展持久存储、不连接本地服务或第三方接口。内存释放不是操作系统级安全擦除。

## 常见情况

- 普通窗口打开扩展：显示提示并禁止导入。
- 其他网站或浏览器内部页：先在无痕窗口打开 ChatGPT，再重新打开扩展。
- 无法确定 Cookie 存储区：不会猜测存储区编号，直接停止。
- 写入失败：尝试清理本次产生的登录 Cookie；若无法确认清理，提示关闭全部无痕窗口。
- 导入后账号仍不可用：本版没有验证会话有效性；该内部 Cookie 名称、结构或网站验证要求可能变化。

## 技术范围

仅申请 `cookies` 和 ChatGPT 主站权限。本版凭证由用户在扩展中主动粘贴。
